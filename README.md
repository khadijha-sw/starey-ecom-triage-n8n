## 🎯 Overview
`starey-ecom-triage-n8n` is a low-code automation blueprint engineered for modern e-commerce stores. It intercepts incoming customer DMs and webhooks 24/7, scores buyer intent using OpenAI, and instantly routes high-priority leads for maximum conversion.

## ✨ Key Features
- **Webhook Integration:** Listens to real-time e-commerce lead triggers.
- **AI Intent Scoring:** Classifies customer intent automatically (High, Medium, Low).
- **Smart Lead Routing:** Filters high-ticket prospects to drive instant proposals.

## 🛠️ Stack & Architecture
- **Engine:** n8n Visual Low-Code Automation Framework
- **Format:** Standard JSON Schema (`STAREY E-Commerce Lead Triage Engine.json`)
- **AI Model:** OpenAI API Node Integration

## 🚀 Quick Start
1. Open your local **n8n** visual canvas (`localhost:5678`).
2. Copy the content inside `STAREY E-Commerce Lead Triage Engine.json` and paste (`Ctrl + V`) directly onto your canvas.
3. Attach your OpenAI credentials and active store Webhook URL.
